# WorldMapSystem

Настраиваемая карта и миникарта для Unreal Engine 5: подземелья из готовых комнат, этажи, публичные городские области, командное исследование и обнаруженные противники.

Первая версия **0.1.0**, исходный C++ Runtime-плагин. Разработка и проверка — **Unreal Engine 5.8.2, Windows x64**. Совместимость с другими версиями UE пока не подтверждена.

## Когда Использовать

Используй систему для миникарты, большой карты, общего исследования команды, этажей и последних известных позиций обнаруженных целей. Подготовленная геометрия карты задается Data Assets и компонентами; генерацию комнат и обнаружение противников подключает проект.

## Главная Модель

`WorldMapManager` хранит серверный реестр, исследование и наблюдения. На каждого игрока сервер назначает `WorldMapViewer`, который получает только разрешенную выборку. Локальные виджеты рисуют данные viewer. Тип элемента задается DA, конкретный экземпляр отличается GUID.

## Первый Рабочий Сценарий

1. Установи плагин в `<Project>/Plugins/WorldMapSystem`, включи его и собери проект.
2. Создай настройки, Map/Floor и определение элемента вручную или скриптом из [FirstRun](Docs/FirstRun.md).
3. Размести один менеджер на persistent level и две `WorldMapRegion` с назначенными Map, Floor и Element DA.
4. На сервере после определения команды вызови `Assign Viewer` для PlayerController.
5. Создай миникарту на локальном клиенте с этим контроллером в `Owning Player`.
6. Войди в объем исследуемой комнаты и проверь ее появление у игроков своей команды.

Ожидаемый результат: команда видит открытый контур, а чужая команда не получает ее исследование. Полная инструкция и диагностика пустой карты: [первый запуск](Docs/FirstRun.md).

## Основные Классы

| Класс | Назначение |
| --- | --- |
| `AWorldMapManager` | Серверный реестр, команды, наблюдения и создание viewer |
| `AWorldMapViewer` | Персональная реплицируемая выборка и запросы пингов |
| `UWorldMapElementComponent` | Регистрация элемента на игровом акторе |
| `AWorldMapRegion` | Область исследования и определения этажа |
| `UWorldMapMinimapWidget`, `UWorldMapFullMapWidget` | Миникарта и большая карта |
| `UWorldMapTooltipWidget` | Карточка разрешенного элемента |
| `UWorldMapSettings`, `UWorldMapViewData` | Серверные настройки и параметры отображения |

## Сетевые Правила

- Команды, роли, исследование и наблюдения определяет сервер.
- Viewer принадлежит игроку; полный реестр менеджера не предназначен для клиентского UI.
- Пинг является запросом с проверками сервера, личная метка остается локальной.
- Смена команды/роли заменяет viewer; данные старого представления перестают быть актуальными.
- Скрытая метка на карте не скрывает информацию, которую другие системы уже передали клиенту.

## Частые Проверки

- На persistent level есть менеджер с назначенными Settings.
- Элемент имеет Map, допустимый Floor, Shape, Style и Visibility.
- Сервер вызвал Assign Viewer, а виджет получил правильный Owning Player.
- Объем региона включает серверную позицию Pawn по XY и Z.
- Повторные процедурные комнаты имеют разные Instance Namespace.
- Ping DA разрешен в настройках, а действие не превышает лимиты.

## Что реализовано

- Все публичные UObject-классы доступны для наследования в Blueprint; структуры данных доступны в BP.
- Data Asset с названием и описанием для команд, ролей, карт, этажей, форм, стилей, состояний, правил видимости, наблюдений, пингов и настроек UI/сервера.
- Поиск по ссылкам на DA. GUID используется только для идентификации конкретного экземпляра и области исследования.
- Реплицируемый `WorldMapManager`; отдельный owner-only `WorldMapViewer` на игрока, Fast Array с разрешённой выборкой.
- Публичная геометрия, командное исследование, роли с обходом исследования, отдельные ограничения видимости состояния.
- Серверные наблюдения с несколькими источниками, последней известной позицией и сроком действия.
- Авторский `WorldMapRegion` с отдельным объёмом присутствия; `WorldMapElementComponent` для готовых Blueprint-объектов; программная регистрация.
- Миникарта и большая карта: контуры и заливки, текстурные кисти, линии, значки, масштаб, панорамирование, выбор этажа, возврат к игроку, фильтры, наведение и пользовательские tooltip-виджеты.
- Личные локальные маркеры и общие командные пинги с серверной проверкой позиции, допустимого DA, частоты и количества.
- Автотесты геометрии, доступа, исследования, наблюдений, серверных ограничений и обновления выборок.

## Границы Ответственности

Это базовая реализация, а не гарантия отсутствия читов или готовый генератор подземелий. Игровой код назначает команды и сообщает серверные результаты обнаружения. Стриминг/генератор подключаются через явные ноды регистрации.

Встроенный viewport прямоугольный. Круговая маска делается внешним UMG Retainer Box и UI-материалом проекта. Навигационный граф, построение маршрута, кластеризация маркеров, пространственный индекс большого города, пиксельный fog-of-war и отдельный формат SaveGame пока не реализованы. Исследование сохраняется/восстанавливается через массив идентификаторов областей.

Крупный город потребует профилирования: отправляются инкрементальные изменения и отсекается невидимая геометрия при рисовании, но сервер пока перебирает записи и объёмы, а hit-test работает линейно. Не следует считать эту версию проверенной на десятках тысяч активных элементов.
