# Первый запуск

## 1. Установка и сборка

Проверяемая версия — UE 5.8.2, Win64. Для сборки исходников нужен установленный C++ toolchain Unreal: Visual Studio 2022 с компонентами разработки игр на C++ и Windows SDK.

Клонируйте репозиторий в каталог плагина:

```powershell
git clone https://github.com/dmitriishobolov/WorldMapSystemUE5Plugin.git "<Project>\Plugins\WorldMapSystem"
```

Если этот каталог уже существует, не клонируйте поверх него: обновите существующий checkout либо перенесите исходники осознанно. `WorldMapSystem.uplugin` должен лежать непосредственно в `Plugins/WorldMapSystem`.

Закройте редактор перед первой сборкой новых отражаемых классов. Сгенерируйте файлы проекта из `.uproject`, соберите конфигурацию `Development Editor` и откройте проект. В `Edit → Plugins` включите **WorldMapSystem**. Live Coding не заменяет полноценную первую сборку/UHT.

## 2. Быстро создать настройки и BP-заготовки

Этот шаг необязателен: runtime не зависит от Python.

1. Включите **Python Editor Script Plugin** и перезапустите редактор, если потребуется.
2. Выполните `Tools → Execute Python Script` и выберите `Plugins/WorldMapSystem/Tools/CreateStarterAssets.py`.
3. В `/Game/WorldMapStarter` появятся DA и BP-заготовки менеджера, области, viewer, миникарты, большой карты и tooltip.

Скрипт создаёт только отсутствующие ассеты. Повторный запуск не меняет ваши настройки, не открывает другую карту и не заменяет GameMode. Заготовка tooltip пустая: её оформление вы создаёте в Designer.

Основные стартовые ассеты:

| Ассет | Назначение |
|---|---|
| `DA_Settings` | Настройки менеджера; разрешён `DA_Ping_Default` |
| `DA_Team_Humans`, `DA_Team_Hunter` | Две независимые команды |
| `DA_Role_Human`, `DA_Role_Hunter` | Обычное исследование / видимость неисследованных комнат |
| `DA_Map_Complex` | Карта с этажами Ground и Basement |
| `DA_Element_Room` | Комната, открываемая исследованием |
| `DA_Element_PublicArea` | Геометрия, видимая сразу |
| `DA_Element_Enemy` | Маркер, доступный только через наблюдение |
| `DA_Observation_Vision` | 0.3 сек актуальности и 5 сек памяти |
| `DA_View_Minimap`, `DA_View_FullMap` | Раздельные настройки виджетов |

Ручной вариант: `Add → Miscellaneous → Data Asset`, выбрать соответствующий класс `WorldMap…`. Каждый DA имеет `Display Name` и `Description`. Можно сначала создать Blueprint-наследника DA-класса, добавить поля проекта, затем создавать его экземпляры.

Минимальная цепочка ручных настроек:

```text
Floor DA → Map DA.Floors
Shape DA + Style DA + Visibility DA → Element DA
Team DA + Role DA → серверный Assign Viewer
Settings DA → менеджер
View DA → виджет
```

Без `Map`, допустимого `Floor`, `Definition.Shape`, `Definition.Style` и `Definition.Visibility` элемент не регистрируется.

## 3. Разметить тестовый уровень

1. Поместите **один** `BP_MapManager` на persistent level. Проверьте его `Settings = DA_Settings`. Менеджер не должен выгружаться вместе с комнатой.
2. Поместите `BP_MapRegion`. На компоненте `Map Element` проверьте `Map`, `Floor = DA_Floor_Ground`, `Definition = DA_Element_Room`.
3. Скопируйте область на другую комнату. Перемещайте и поворачивайте акторы по планировке; `Volume` определяет нахождение Pawn внутри, `Map Element` — рисунок.
4. Для подвала создайте ещё область на Z около -600 и выберите `DA_Floor_Basement`. Для стабильного определения этажа объём должен включать позицию Pawn, обычно центр его капсулы.
5. Чтобы показать публичную область сразу, задайте ей `DA_Element_PublicArea`. Её масштаб/контур могут отличаться от объёма. Публичная подложка города не должна использовать тот же DA определения, что секретная внутренняя планировка.

`Region Settings.Volume Half Extent` задаёт независимый 3D-объём. `Element.Shape` задаёт 2D-контур. Для обычной комнаты значения могут совпадать по XY. Не нужно создавать коллизию для объёма: менеджер сам проверяет серверную позицию Pawn.

## 4. Назначить команды на сервере

В GameMode или другом доверенном серверном коде после `PostLogin`:

```text
Event OnPostLogin(NewPlayer)
    → Find Map Manager
    → Assign Viewer
        Player Controller = NewPlayer
        Team = DA_Team_Humans
        Viewer Role = DA_Role_Human
```

Для маньяка используйте `DA_Team_Hunter` и `DA_Role_Hunter`. Выбор роли делает серверная логика игры, не клиентский RPC с произвольной ссылкой на DA.

Менеджер должен уже существовать в мире. При серверном спавне менеджера после входа игроков пройдитесь по существующим PlayerController и вызовите `Assign Viewer`. При повторном назначении той же команды/роли используется существующий viewer. При смене команды/роли создаётся новый, прежние командные пинги этого игрока удаляются.

На `Logout` вызовите `Remove Viewer`. После смены карты/создания нового менеджера назначьте viewer снова. Dedicated server не создаёт UI.

## 5. Показать миникарту и большую карту

В локальном PlayerController/HUD:

```text
BeginPlay
    → Is Local Controller
    → Create Widget(WBP_Minimap, Owning Player = Self)
    → Add to Viewport
```

Для большой карты создайте `WBP_FullMap` аналогично и открывайте её по действию ввода проекта. Задайте удобный размер/anchors. Нативные виджеты умеют рисоваться без дочерних Image-виджетов. BP-обёртка может добавить рамку, кнопки и подписи поверх карты.

Виджет автоматически ищет owner-only viewer своего `Owning Player`, в том числе если тот пришёл по сети позже. Можно также явно вызвать `Bind Viewer`.

- Колесо мыши — масштабирование.
- ЛКМ с перемещением — панорамирование; следование и автоматический выбор этажа выключаются.
- Кнопка «К игроку» — `Center On Player`.
- Кнопка этажа — `Set Displayed Floor(Map DA, Floor DA)`.
- Для взаимодействия включите курсор PlayerController и нужный режим ввода `Game and UI` или `UI Only` средствами проекта.

`Set Displayed Floor` отключает только автоматическое переключение этажа. `Center On Player` возвращает центр, этаж и следование. Zoom и выбранный этаж хранятся отдельно в каждом экземпляре виджета.

## 6. Наведение и карточка объекта

1. Оформите `WBP_MapTooltip`, родитель — `WorldMapTooltipWidget`.
2. Реализуйте событие `Update From Map Element`.
3. Используйте `Element.Definition.DisplayName`, `Description`, разрешённый `State` и `bLastKnown`.
4. Укажите этот BP в `Element DA.Tooltip Class`.

При отсутствии tooltip-класса используется простая подсказка с названием DA. В карточке нет ссылки на исходный игровой Actor: это намеренное ограничение сетевого представления. Для игрового действия передавайте `Element.Id` в собственный серверный обработчик с повторной проверкой прав.

## 7. Пинги и личные метки

Добавьте кнопку/действие пинга проекта. Из локального виджета используйте `Request Ping At Local Position`, либо вызовите на viewer `Server Request Ping` с `DA_Ping_Default`, выбранной картой, этажом и мировыми XY.

`On Map Clicked` срабатывает при клике по пустому месту; `On Element Clicked` — по интерактивному элементу. Для пинга по центру элемента используйте его `Transform.Location`. Для пинга в точной позиции курсора вызовите `Request Ping At Local Position` из собственного обработчика ввода.

Сервер проверит whitelist, команду, частоту, квоту, расстояние от Pawn и попадание в доступную геометрию. Z вычисляет сервер. Данные других команд в запрос не передаются. Пинги не переживают отключение автора или смену его команды.

Для личной заметки используйте `Add Personal Marker`; она живёт локально до удаления/замены viewer и никуда не реплицируется. Она не является игровым подтверждением обнаружения.

## 8. Обнаруженный противник

Добавьте противнику `WorldMapElementComponent`, настройте карту, исходный этаж и `DA_Element_Enemy`. На сервере после регистрации получите `Get Element Id`.

Доверенная система зрения/сканирования:

```text
Пока цель действительно обнаружена сервером:
    Report Observation(Team DA, Enemy Element Id, DA_Observation_Vision, Observer Actor)

Контакт потерян:
    End Observation(..., Keep Memory = true)
```

Повторяйте сообщения чаще `Fresh Seconds` (для стартового DA, например, раз в 0.1 сек). Наблюдение содержит снимок позиции/этажа/состояния на момент сообщения. Даже во время актуальности метка не получает несообщённое перемещение. После потери контакта она тускнеет на последней позиции, затем исчезает.

## 9. Комнаты генератора

Для каждой комнаты задайте свой `Instance Namespace` до регистрации. Все элементы внутри комнаты используют этот namespace, а `Local Element Id` различается по элементам. Общий локальный `Exploration Id` объединяет комнату, двери и связанные метки для открытия одной области.

Если генератор назначает параметры после BeginPlay, заранее выключите `Auto Register`; после размещения вызовите `Register With Manager`, а для `WorldMapRegion` — `Register Region With Manager`.

В Level Instance повторяются сериализованные локальные GUID. Генератор/адаптер должен передать новый namespace всем компонентам конкретного экземпляра после загрузки. Встроенного адаптера к конкретному генератору или Level Instance API пока нет. Поиск по `Element DA` вернёт несколько экземпляров — выбирайте нужный по GUID.

## 10. Проверить кооператив

Запустите PIE с отдельным сервером и минимум двумя клиентами. Проверьте:

- публичная область видна обоим;
- люди открывают комнаты только своей команде;
- роль маньяка видит неисследованные комнаты, но не человеческие пинги/наблюдения;
- поздний вход получает исследование своей команды;
- после потери контакта враг не двигается на карте;
- ручной выбор этажа большой карты не меняет миникарту;
- смена роли/команды заменяет viewer и убирает недоступные записи;
- выгрузка комнаты сохраняет её контур, но явное уничтожение/удаление убирает запись.

Автоматические проверки и их границы описаны в [Testing](Testing.md).

## Если карта пустая

| Симптом | Проверка |
|---|---|
| Вообще нет элементов | Вызван ли `Assign Viewer` на сервере? Есть ли `Owning Player` у виджета? |
| Только исследуемые комнаты скрыты | Pawn внутри объёма? Совпадает ли команда? Включено ли открытие по входу? |
| Одна из одинаковых комнат не появляется | Предупреждение `Duplicate map Id` в логе; нужен уникальный namespace |
| Элемент отвергнут | Все обязательные DA назначены? Floor присутствует в Map.Floors? Контур допустим? |
| Не меняется этаж | Объём включает Pawn по Z? Не выбран ли вручную этаж? Истекла ли задержка? |
| Не работает мышь | `View Settings.Interactive`, курсор и режим ввода, перекрывающие UMG-виджеты |
| Нет пинга | DA входит в Allowed Pings? Есть Pawn? Доступная область, дистанция, лимит и cooldown? |
| Native-классы не появляются | Полная сборка Development Editor, включённый плагин, перезапуск редактора |
